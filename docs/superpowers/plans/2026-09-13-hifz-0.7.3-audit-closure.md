# Quran Hifz 0.7.3 Audit Closure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close every actionable Claude audit finding plus the newly frozen sliding 7-day dashboard rule, while keeping audio, signing, merge and publication out of scope.

**Architecture:** Keep schedule policy in `HifzSchedule`, queue policy in pure helpers, and persistence in `HifzPrefs`. Promotion attendance becomes durable Hifz state rather than a dashboard-history side effect. Dashboard Ancrage projection consumes the persisted anchoring visit order so home and session agree. Main-thread queue reconstruction is cached/prewarmed; the remaining e-ink rendering/latency questions stay physical-BOOX gates.

**Tech Stack:** Android/Java, Kotlin hifz-core, SharedPreferences schema 4, JUnit4, AndroidJUnitRunner, GitHub Actions emulator.

**Spec:** `QURAN_HIFZ_0.7.3_CLAUDE_INDEPENDENT_AUDIT.md` plus user decision in this conversation: sliding calendar starts with today and displays today..J+6 with no past empty rows.
