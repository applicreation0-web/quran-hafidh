# Terminologie anglaise — choix provisoires

Statut : échantillon documentaire initial, insuffisant pour figer un lexique
sur 114 sourates. « Retenu provisoirement » ne signifie pas traduction publiée
du texte de Sharjah. Les références sont détaillées dans SOURCE_AUDIT.

| Arabe | Anglais retrouvé / examiné | Contextes constatés | Choix provisoire et raison |
|---|---|---|---|
| محور السورة | Central theme ; thematic axis ; principal theme ; main theme | Central theme : Moderasi, GISTU, Dar al-Ifta. Thematic axis : GISTU. Principal theme : Moderasi. Main theme(s) : El-Mesawi p. 3 | Central theme pour l'interface ; thematic axis pour expliquer le terme technique. Choix non définitif |
| مقطع | Unit ; section ; passage | El-Mesawi pp. 4–5 emploie unit pour les blocs de Draz ; ce n'est pas une traduction publiée des مقاطع Sharjah | Section, provisoire ; conserver séparément le libellé source et le niveau |
| مقصد | Objective ; purpose | El-Mesawi p. 2 rapproche objectives de maqasid ; purpose intervient aussi pour gharad p. 4 | Purpose au singulier selon contexte ; ne pas l'assimiler automatiquement à محور |
| مناسبة | Coherence ; textual relation | El-Mesawi p. 3 décrit les munasabat par la cohérence entre versets et sourates ; étude USIM repérée avec textual relations dans son titre | Relation, provisoire, avec les deux objets reliés ; pas de causalité ajoutée |
| الوحدة الموضوعية | Thematic unity | El-Mesawi p. 2 ; titre/résumé anglais GISTU | Thematic unity |

Fréquences : les nombres ci-dessus comptent des **documents pertinents retrouvés**,
pas des occurrences ni une fréquence dans toute la littérature. Échantillon biaisé
par les requêtes. Aucun résultat chiffré de prévalence académique n'est avancé.

Core theme, core purpose et main purpose ont été recherchés. Les résultats
consultés ne suffisent pas à les établir comme équivalents directs de محور dans
Sharjah. « Purpose » privilégie la finalité, tandis que « theme » privilégie le
sujet unificateur : ne pas les interchanger sans lire le paragraphe source.

## Statuts applicables à chaque intitulé

- PUBLISHED_EXACT : intitulé arabe + anglais correspondant + référence précise.
- PUBLISHED_PARAPHRASE : relation démontrée, paraphrase signalée.
- EDITORIAL_VERIFIED : traduction depuis l'arabe, terminologie et littérature
  comparées, rétrotraduction et contrôle consignés ; validation éditoriale interne,
  sans prétendre à une traduction publiée ou à une validation par un savant.
- SOURCE_UNRESOLVED : pas de texte anglais validé. Une suggestion éventuelle reste
  dans editorialDraftEn et ne doit pas être affichée comme traduction finale.

## Contrôle éditorial à consigner

Pour chaque titre : identifiant ; arabe exact ; page source ; requêtes de recherche ;
références rejetées/acceptées ; premier anglais ; contrôle terminologique ; comparaison
avec travaux sur la sourate ; rétrotraduction ; différences de sens ; révision ;
responsable et date. Le contrôle automatisé ne peut pas certifier le sens.

Les quatre propositions anglaises de Qaf présentes dans le JSON sont des brouillons.
Elles n'ont volontairement **aucun statut de traduction validée**. En particulier,
le choix entre self/selves/human beings et outcome/destiny demande encore un contrôle
du contexte. Aucun sens théologique supplémentaire ne doit être ajouté.
